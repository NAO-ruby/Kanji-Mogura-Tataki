# 漢字もぐらたたき！～めざせ漢字王～

漢字の札を持ったもぐらを選ぶブラウザゲームです。漢検3級・準2級・2級の目安に合わせたオリジナル問題を各30問、合計90問収録しています。初級は読みの問題を中心に、中級・上級は意味や四字熟語の問題が増えます。[漢検の各級の概要](https://www.kanken.or.jp/kanken/grades/overview/)

## パソコンで遊ぶ

1. エクスプローラーで「自作ゲームもぐらたたき」フォルダを開きます。
2. `index.html` をダブルクリックすると、標準のブラウザが開きます。
3. ゲームモード、難易度、制限時間を選んで「ゲームスタート」を押します。

4つのゲームファイルは同じフォルダに置いてください。インターネット接続や追加インストールは不要です。音は「ゲームスタート」を押してから鳴ります。画面右上で音量やミュートを変更できます。

## 遊び方

- 問題に合う札をクリックします。スマートフォンではタップします。
- 正解は＋10点、不正解は−5点です。得点の下限は0点です。3・5・10連続正解に達した回は、それぞれ＋5・＋10・＋20点が加わります。誤答や問題ごとの時間切れで連続正解が途切れます。
- CPU対戦では、各問題で先に正解した側が得点します。CPUにも同じ得点とコンボのルールが適用されます。CPUが先に正解しても、こちらの連続正解や不正解数には影響しません。
- 「一時停止」を押すと、残り時間と対戦が止まります。Escキーでも一時停止・再開できます。
- 結果の正解率は、クリックして回答した回数に対する正解の割合です。誤答や時間切れになった問題は「間違えた漢字を復習する」から確認でき、時間無制限で再挑戦できます。
- 1人プレイの最高得点は難易度別にブラウザへ保存されます。端末、ブラウザ、または起動するURLが変わると記録も別になります。
- 称号は正解率と1秒あたりの得点を使い、難易度とCPUの強さに応じて基準を調整しています。時間無制限の復習では正解率で判定します。

## GitHub Pagesで公開する

1. GitHubにログインし、「New repository」でリポジトリを新規作成します。名前は例として `kanji-mogura` を使います。誰でも遊べるようにする場合は「Public」を選びます。
2. リポジトリの「Add file」→「Upload files」を開き、このフォルダにある `index.html`、`style.css`、`questions.js`、`game.js` をアップロードします。4つのファイルがリポジトリの一番上に並ぶようにします。この説明書も必要に応じて追加できます。
3. 「Commit changes」を押して保存します。
4. リポジトリの「Settings」→「Pages」を開きます。「Build and deployment」の「Source」で「Deploy from a branch」を選び、ブランチに `main`、フォルダに `/(root)` を指定し、「Save」を押します。
5. 公開が完了したら、同じ「Pages」画面の「Visit site」を押します。例の設定なら公開先は `https://ユーザー名.github.io/kanji-mogura/` です。このURLをスマートフォンや提出先で開けます。[GitHub公式の公開設定手順](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

もぐらと背景はHTMLとCSSで描画し、効果音はWeb Audio APIで合成しています。
